# 📊 HR Analytics & Employee Performance Dashboard

An interactive Excel dashboard designed to analyze employee data, monitor workforce performance, and generate meaningful HR insights through data visualization.

## 📌 Project Overview

The **HR Analytics & Employee Performance Dashboard** is an Excel-based data analytics project that transforms employee information into meaningful visual insights.

The dashboard helps HR teams understand workforce distribution, analyze employee performance, monitor attendance, evaluate salary trends, and track employee attrition.

## 🎯 Project Objectives

- Analyze employee distribution across departments.
- Monitor employee performance and attendance.
- Understand salary distribution and experience levels.
- Analyze employee attrition across departments.
- Explore workforce demographics.
- Support HR decision-making through data visualization.

## 📊 Dashboard Features

### Key Performance Indicators (KPIs)

- Total Employees
- Average Salary
- Average Experience
- Attrition Count
- Attrition Rate
- Average Attendance

### Interactive Visualizations

- Employee Count by Department
- Gender Distribution
- Salary Distribution
- Employee Attrition by Department
- Employee Performance Rating by Department
- Average Salary by Experience

### Interactive Filters

- Department Slicer
- Gender Slicer
- Job Role Slicer
- Joining Date Timeline

### Additional Analysis

- Department-wise employee analysis
- Performance rating analysis
- Attendance analysis
- Overtime analysis
- Experience analysis
- Education distribution

## 📂 Dataset Information

The project uses a synthetic HR employee dataset containing 1,000 employee records.

The dataset includes:

- Employee ID
- Employee Name
- Gender
- Age
- Department
- Job Role
- Joining Date
- Salary
- Experience
- Performance Rating
- Attendance
- Overtime
- Attrition
- Education

**Note:** The uploaded dataset is a reconstructed synthetic dataset matching the project's structure and key summary figures. Individual records may not exactly match the source data used in the dashboard.

- How does attendance vary across departments?

## 🚀 How to Use

1. Download the Excel dashboard from this repository.
2. Open it using Microsoft Excel.
3. Navigate to the **HR Dashboard** sheet.
4. Explore the KPIs and charts.
5. Use the slicers to filter by department, gender, and job role.
6. Use the joining date timeline to explore different periods.
